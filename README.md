# Arduino Components Overview

This project uses an **Arduino Uno** with multiple input/output modules, sensors, and actuators.  
Below is a list of all hardware components used in the project.

| Image | Component |
|------|----------|
| <img src="img/arduino_uno.png" width="480"/> | **Arduino Uno**<br>Main microcontroller board used to control all components and run the project logic. |
| <img src="img/leds.png" width="480"/> | **LEDs (Red, Blue, Green)**<br>Used as visual indicators for status, signals, or debugging. |
| <img src="img/buttons.png" width="480"/> | **Buttons**<br>Provide digital input for user interaction and control actions. |
| <img src="img/buzzer.png" width="480"/> | **Buzzer**<br>Generates sound alerts, notifications, or feedback. |
| <img src="LCD_display/img/LCD1602_I2C.jpg" width="480"/> | **LCD 1602 Display (I2C / QAPASS)**<br>Used to display text, menu options, numerical outputs, or system status screens. |
| <img src="img/display_3461bs1.jpg" width="480"/> | **4-Digit 7-Segment Display (3461BS-1)**<br>Common-anode multiplexed display used to output numbers, dynamic decimal points, and status messages. |
| <img src="img/74hc595.png" width="480"/> | **74HC595 Shift Register**<br>8-bit serial-in parallel-out shift register used to drive display segments using minimal microcontroller pins. |
| <img src="img/keypad_hw834.jpg" width="480"/> | **4x4 Matrix Keypad (HW-834)**<br>Provides 16-button input layout for numerical entries, decimal points, and mathematical operations. |
| <img src="img/matrix_1588bs.jpg" width="480"/> | **8×8 LED Matrix (1588BS)**<br>Common-cathode LED matrix used to display characters, icons, and animations via row/column scanning. |
| <img src="img/rtc_module.jpg" width="480"/> | **Real-Time Clock (RTC) Module**<br>Keeps track of time and date even when the system is powered off. |
| <img src="img/28byj48.png" width="480"/> | **28BYJ-48 Geared Stepper Motor (12V) with Driver Module**<br>Stepper motor with built-in gearbox, providing precise rotational control, supplied with a dedicated control board. |
| <img src="img/joystick_hw504.jpg" width="480"/> | **Joystick HW-504**<br>Provides analog input for directional control (X/Y axis + button). |
| <img src="img/microphone.png" width="480"/> | **Microphone Module (Hoya)**<br>Detects sound levels or audio input. |
| <img src="img/button_h85_55.jpg" width="480"/> | **Button Module H85/55**<br>Dedicated button module for triggering actions or events. |
